# Data pipeline

Run `python3 scripts/data/evaluate_corridors.py`, then `python3 scripts/data/build_corridor.py`, `python3 scripts/data/build_terrain.py`, `python3 scripts/data/build_imagery.py`, `python3 scripts/data/build_landscape.py`, `python3 scripts/data/build_buildings.py`, and `python3 scripts/data/validate_corridor.py`.

Raw/cached downloads are ignored. `build_imagery.py` derives exact LV95 WMS bounds from the canonical local origin, caches source JPEG responses, encodes WebP, hashes filenames and regenerates the scenery manifest. `build_landscape.py` caches a corridor Overpass extract, clips its geometry in the canonical local frame and deterministically samples trees within real forest polygons while excluding an 18 m railway envelope. `build_buildings.py` queries the official SWISELD asset API, caches the ten intersecting CityGML archives, crops LOD2 surfaces, de-duplicates vertices, batches four indexed Float32/Uint32 runtime meshes and records every source asset ID. Network and invalid-response errors stop generation with a diagnostic rather than emitting empty assets.
