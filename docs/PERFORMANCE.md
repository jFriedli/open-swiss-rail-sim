# Performance

Production build measured 24 August 2026: JavaScript 513 kB (131 kB gzip), CSS 4.0 kB (1.6 kB gzip), WASM 15.6 kB (7.1 kB gzip), route JSON 92 kB and terrain JSON 60 kB. The 204 × 48 regular terrain grid has 9,792 vertices and 19,082 triangles over 15.225 × 3.525 km. The scene uses instanced sleepers/catenary and exposes FPS, draw calls and rendered triangles in `?debug=1` mode. Diagnostic scenes report roughly 164k–178k rendered triangles and 55–143 draw calls depending on visible signals. Headless SwiftShader screenshot FPS is not representative of hardware performance, so no unsupported desktop figure is claimed.

SWISSIMAGE adds four WebP files totalling 2.115 MB transfer. Their decoded RGB/RGBA texture-memory estimate is about 60 MiB. Images are approximately 1.85 m/pixel, use generated mipmaps and maximum supported anisotropic filtering.

Landscape JSON is 0.40 MB and represents 131 water polygons, 149 forest polygons, 2,242 trees, 1,240 road features/171.2 km, and ten platforms. Trees use two instanced draw calls and roads one merged mesh. Official building runtime assets total 18.48 MB: 7,974 buildings, 418,958 unique vertices and 1,120,908 triangles in four sector meshes. Only the current and forward-adjacent building sectors load; the complete runtime package is about 21.3 MB plus application files. A typical rendered checkpoint with one building sector reports roughly 0.79 million triangles and 66–81 draw calls. Headless SwiftShader reports only 2–4 FPS with the building geometry and is explicitly not a desktop-GPU measurement.
